第 158/208 课：Transformer 与注意力

序号 158/208 · id k-transformer · 领域 K · 阶段 2 · 难度 基础 · 子类 模型接口与输出 前置：k-ml 节点摘要：Self-attention 让每个位置按权重聚合上下文；训练可并行，生成通常串行。

导读

读到「模型根据上下文改写了输出」，不要停在比喻。把一小段向量、一套权重算出来，看上下文增加时第一个位置的输出怎样变，比空谈架构图更有用。

本课实践是一个极小的、可逐步打印的 attention，维度 d_model=4，用 numpy 计算。is_live_model=false。它不是 GPT 的复现，也没有训练一个语言模型；它用来把公式变成数字。

学习目标

  1. 解释 self-attention 及适用边界
  2. 独立完成实践：用一个极小 attention 示例计算权重，观察加入上下文后输出改变。

为什么后端要懂

上下文长度、KV cache、截断策略，背后都是「每个新词都要和已有位置算注意力」。搞混训练并行和生成串行，就会误判延迟和计费。

核心知识点

1. Self-attention

直觉。 每个位置先把自己变成 query、把所有位置变成 key 和 value；query 与 key 的点积决定「我该看谁」，再按这些权重把 value 加起来。

原理。 2026-11-15 抓取 Attention Is All You Need 摘要页（https://arxiv.org/abs/1706.03762，Date 2026-11-15 22:58:54 CST，Last-Modified 2026-08-25 04:04:45 CST，43071 字节）。论文（v7）给出缩放点积注意力：

[ \mathrm{Attention}(Q,K,V)=\mathrm{softmax}!\left(\frac{QK^\top}{\sqrt{d}}\right)V ]

attention.py 逐步实现：scores = (q @ k.T) / sqrt(d)，再 softmax，再乘 v。本机短序列 ["query","host"] 第一行权重约为 [0.584, 0.416]；加上 "disk","full" 之后第一行变成 [0.3344, 0.2382, 0.1882, 0.2392]，第一个位置的输出向量从约 [-0.666, 0.525, 1.447, 1.861] 变为 [-0.893, 0.772, 1.939, 2.296]。query_output_changed_with_context=true。这就是节点实践要观察的现象：同一位置的表示依赖于整段上下文。

适用边界。 权重是「这个玩具例子里的分配」，不是对真实模型决策的可靠解释。结果里写明 attention_weights_are_not_a_causal_explanation=true。节点陷阱正是「认为注意力权重就是可靠解释」。

2. 位置编码

直觉。 若只做点积，交换两个词的位置，集合关系几乎不变。要让模型知道顺序，需要把位置信息加进表示。

原理与实践。 positions(n, d, scale=0.15) 生成一个与序列等长的小扰动并加到输入上。这是教学用的简化，不是论文里的正弦位置编码，更不是 RoPE。它只用来说明「位置必须被显式注入」。不要把本函数的数值当成 Transformer 标准实现的复现。

3. 自回归解码：训练可并行，生成串行

直觉。 训练时每个位置的正确答案已经在数据里（teacher forcing），可以一次算整句，但要用因果掩码禁止看见未来；生成时下一个词还没产生，只能一个一个来。

原理。 causal_mask(n) 把上三角写成 -inf，softmax 后对应权重为 0。本机在同一套输入上比较：带因果掩码的整段并行结果的最后一个位置，与按位置串行累计（每一步只看到已经出现的 token）得到的最后输出，数值一致（约 [-0.8692, 0.7561, 1.926, 2.2888]）。serial_matches_parallel_given_same_inputs=true，同时 generation_is_serial=true：真实生成仍要逐步追加 token，不能预先知道未来词。

参数记忆与外部检索：这个例子没有任何文档索引。参数里只有随机/教学权重能编码的模式。检索是另一套系统（见第 160 课）。结果中的 parameter_memory_vs_retrieval 记录了这一区分，避免把 attention 当成已经「查过资料」。

常见误区

  • 认为注意力权重就是可靠解释。
  • 以为训练时的并行前向等于推理时也可以一次得到全部新词。
  • 把本课 4 维玩具的权重数字用于解释线上大模型。

设计权衡

更长上下文让每个位置都能看见更多证据，但计算近似按序列长度平方增长（标准注意力），也更容易引入干扰。具体成本依实现（FlashAttention、窗口注意力等）而异，本课未测那些内核。

自测题

1. 为什么要除以 (\sqrt{d})？

答案：点积的量级随维度增大，softmax 会变陡、梯度变差。论文用缩放缓解这一点。本课 d=4 时缩放是 2。

2. 因果掩码如果漏了，训练时会出现什么问题？

答案：位置 i 能看见 i 之后的 token，相当于偷看未来。训练损失会好看，自回归生成时却对不上。

3. 本课证明了「加上下文会改输出」。这能证明大模型已经理解了磁盘故障吗？

答案：不能。它只证明了该机制会混合后续位置的向量。语义理解需要真实模型和数据，本课没有。

本课小结

Self-attention 用缩放点积混合上下文；位置要另行注入；训练可在因果掩码下并行，生成仍然串行。本课用 4 维可复现数字验证了这些机制，不把注意力权重当成解释，也不把玩具模型当成大模型。
